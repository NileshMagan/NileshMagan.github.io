$ review --pull-request→ triage, then specialist reviewers in parallel→ one consolidated comment · cost cap US$2 per PR
Anthropic API · Code review

Multi-agent PR reviewer

An AI pull-request reviewer built on the Anthropic API from cooperating agents. It triages each pull request, runs specialist reviewers in parallel for frontend, backend, mobile, SRE and product, and posts a single comment. Used across the engineering team: it reviews every pull request as soon as it is opened, has caught real bugs, and opens its own PRs to improve the repos. Models and cost are configurable.

Daily practice

Agentic workflow

I work with coding agents every day: parallel agents in separate git worktrees, sub-agents on cheaper models for delegated work, and custom hooks and review tooling. That includes a browser diff viewer I review in before every commit, which keeps a human in the loop.

How I approach itCost caps on what agents can spend, evals and verifier gates before I trust their output, and human review before anything is committed.
